# v1.0.1 验证记录

日期：2026-10-07。主要验证环境：Windows 10 22H2 x64；Rust 1.99.0、MSVC x64、Typst 0.15.1。此记录只描述实际执行的本地检查。

## 源码

- `cargo fmt --all -- --check` 通过。
- `cargo test --workspace --locked --offline`：101 项测试通过（核心 77 项，客户端 24 项）。覆盖资料独立性、类别/素材排序、保存反馈、冲突保护、数据库升级、备份/恢复、历史 PDF、排版与缓存释放。
- `cargo clippy --workspace --all-targets --locked --offline -- -D warnings` 通过。
- 补充链接内容的排版查询断言后，复测 7 项排版测试及 1 项选色测试，全部通过。
- 本次不新增数据库迁移，仍使用 schema 6；颜色及分组数据格式兼容既有资料。
- 源码发布范围未包含个人数据库、备份或运行时 EXE/DLL。

## 本次问题回归

- 图形选色：使用 egui 指针事件打开色盘并点击饱和度/明度区域，确认颜色实际改变；保存为简历和版式预设后关闭并重开资料库，颜色一致。
- 自定义大类：两种命名类别与教育、项目经历各自作为一级标题；改名的内置自定义类别不被通用版式标题覆盖。
- 已有简历：通过界面点击“使用资料库名称”后保存，当前标题更新，改名前历史标题保持不变。
- 排版：新格式和旧格式均导出匿名样例，Typst 查询确认四个类别标题及两条链接的可见内容。pypdf 从实际 PDF 验证完整网址、空标签链接、跨行链接的原始 URI，以及没有通用“自定义”标题。
- 主题色：pdfplumber 检查实际 PDF 标题文字的颜色与设置一致；Poppler 将两个 PDF 渲染为 PNG 并视觉检查，未见重叠、裁切或丢字。
