# Nisaba CV v1.1

自定义类别采用先命名、再添加素材的流程，作为与教育、工作、项目、技能并列的大类。

## 如何使用

1. 在资料库首页“新建自定义类别”处输入“爱好”，点击“创建类别”。
2. “爱好”会单独出现在资料库里。点击该类别的“添加素材”，录入“阅读”“摄影”等具体内容。
3. 新建简历时，从“爱好”等大类中挑选素材，调整大类和素材顺序。
4. PDF 直接使用“爱好”作为一级标题，与“教育经历”“项目经历”“技能”同级；不再套一层“自定义”标题。
5. 不用的自建类别可点击“删除类别”。确认后删除类别及其中所有资料库素材（包括归档和回收站），无法撤销；已生成的独立简历保留。

新资料库仅预置教育、工作、项目和技能四类，没有默认“自定义”总类。保留项目完整网址显示、PDF 点击跳转及图形主题色选择。

## 下载

下载 `Nisaba-CV-v1.1-windows-x64.exe`，解压到新目录或空文件夹，默认文件夹名仍为 `Nisaba CV`。运行其中的 `Nisaba-CV.exe`。字体和排版工具已包含，无需 WebView2 或联网。

若要保留现有资料，请先导出完整备份。新版包会拒绝覆盖含文件的目录，避免直接覆盖程序和资料。
