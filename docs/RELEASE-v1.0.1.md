# Nisaba CV v1.0.1

修复项目网址和自定义类别标题的显示，主题色改用图形选色。

- 项目链接显示名称和完整网址；名称留空时也能显示网址，PDF 中可点击跳转，长网址自动换行。
- 新简历使用命名后的类别作为一级标题。已改名的内置类别不再被版式预设中的通用标题覆盖；旧格式简历的新导出按类别分组。
- 已有简历保留自己的标题；在“类别标题”旁点击“使用资料库名称”，保存后重新预览/导出即可更新。已有历史 PDF 保持原样。
- 点击“主题色”旁的色块，在色盘中自由选色。颜色保存在本地简历和版式预设中。

## 下载和升级

下载 `Nisaba-CV-v1.0.1-windows-x64.exe` 和可选的 `SHA256SUMS.txt`。在 Release 页面下方的附件区域下载，源码无需普通使用者编译。

先在旧版“备份与设置”中导出完整备份，再关闭旧版。将新版解压到新的目录或空文件夹，默认文件夹名仍为 `Nisaba CV`；打开新版并恢复备份。确认资料和历史版本完整后再处理旧目录。此自解压包会拒绝直接覆盖含文件的旧目录。

原生 Windows x64 界面，PDF 导出；包内包含字体和排版工具，运行无需 WebView2 或联网。开发使用 AI 辅助，声明见 README；源码采用 MIT。

本地检查见 [验证记录](https://github.com/NaruseYozora/nisaba-cv/blob/main/docs/VERIFICATION-v1.0.1.md)。Windows 11、干净系统、物理断网及真实输入法/DPI 的全面实机覆盖仍待补充；发行包暂未进行代码签名。
