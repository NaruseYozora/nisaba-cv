# Nisaba CV v1.0

首个公开版本。一个 Windows 本地简历工具：维护个人信息、经历和技能库，为不同岗位挑选素材、独立改写简历并导出 PDF。

## 下载

下载 `Nisaba-CV-v1.0-windows-x64.exe`，运行后选择新目录或已有空文件夹。默认目录名为 `Nisaba CV`，解压后双击其中的 `Nisaba-CV.exe`。字体、排版工具及所需运行库均已包含，无需 WebView2、账号或额外下载。

`SHA256SUMS.txt` 用于核对下载文件。源码由本 Release 的标签提供。

## 本版功能

- 个人信息、自定义字段、教育、工作、项目、技能和自定义类别库。
- 按类别与素材排序、成果选材、独立简历副本及选材预设。
- 版式、照片、多页 PDF 预览与导出。
- 命名版本、原始历史 PDF、完整备份和自动备份。
- MIT 许可证、AI 开发声明及开发维护文档。

资料默认保存在程序旁的 `nisaba-data`。升级前导出完整备份，将新版本解压到空目录后恢复；不要覆盖正在保存资料的旧程序目录。

## 验证与已知限制

v1.0 在 Windows 10 22H2 完成源码回归及自解压包验证，详细记录见 [验证说明](VERIFICATION-v1.0.md)。Windows 11、干净系统、物理断网、真实输入法和系统 DPI 的全面实机测试仍待补充。发行文件暂未进行代码签名；当前仅提供 Windows x64 和 PDF 导出。
