# v1.1 验证记录

日期：2026-10-07。主要验证环境：Windows 10 22H2 x64；Rust 1.99.0、MSVC x64、Typst 0.15.1。此记录只描述实际执行的本地检查。

## 源码

- `cargo fmt --all -- --check` 通过。
- `cargo test --workspace --locked --offline`：103 项测试通过（核心 78 项，客户端 25 项）。覆盖资料独立性、类别/素材排序、保存反馈、冲突保护、数据库升级、备份/恢复、历史 PDF、排版与缓存释放。
- `cargo clippy --workspace --all-targets --locked --offline -- -D warnings` 通过。
- 完善类别校验和界面流程断言后，复测 21 项类别测试及 17 项客户端界面测试，全部通过。
- 数据库结构版本为 schema 7：新资料库不再预置“自定义”总类，命名的自建类别可删除。未改写已经发布的六份 SQL 迁移文件。
- 源码发布范围未包含个人数据库、备份或运行时 EXE/DLL。

## 本次问题回归

- 图形选色：使用 egui 指针事件打开色盘并点击饱和度/明度区域，确认颜色实际改变；保存为简历和版式预设后关闭并重开资料库，颜色一致。
- 默认分类：新资料库仅有教育、工作、项目和技能四类，不存在“自定义”总类。
- 界面完整流程：egui 指针和文本输入事件在资料库输入“爱好”、创建类别、点击该类别的“添加素材”、保存“阅读”；新建简历时通过复选框选入教育、项目、技能和爱好素材，点击“生成简历”后实际导出 PDF。
- PDF 检查：pypdf 确认出现“教育经历、项目经历、技能、爱好”，没有“自定义”；pdfplumber 确认四个标题均为 12 pt，同级排列。Poppler 渲染后视觉检查未见重叠、裁切或丢字。
- 删除：实际点击“删除类别”，先取消确认，再重新确认删除；类别和素材消失，当前类别筛选清空，已生成简历保持独立。核心测试额外覆盖同时删除使用中、归档和回收站素材，以及冲突时不执行删除。
- 保留项目完整网址、空链接名称及长网址换行；图形选色仍可保存并重开。
- 原生 OpenGL 截图：独立匿名资料库完成资料库、个人信息、教育编辑、选材、简历编辑、保存反馈、PDF 和历史 PDF 八个界面截图，记录无应用错误，事件循环结束。外部首次等待退出超时，随后按测试程序的绝对路径确认进程已退出。README 界面图已更新。
