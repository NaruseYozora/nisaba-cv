# Nisaba CV v1.0

Windows 本地简历工具。维护个人信息、经历和技能库，按岗位选材、改写简历并导出 PDF。

## 开始使用

双击本文件夹内的 `Nisaba-CV.exe`。字体、排版工具和所需运行库已包含，无需 WebView2、账号或额外安装。请保留整个文件夹。

先录入个人信息，在资料库维护类别与素材；新建简历时安排大类，再选择具体素材和成果。保存后预览/导出 PDF。Ctrl+S 保存，“保存并返回”回到上一级；深色提示表示操作完成。

简历可独立改写，资料库与其他简历保持独立。版本历史支持命名版本和查看原始 PDF；“备份与设置”提供完整备份、恢复及实际资料目录。

## 保存、升级与移除

个人资料默认保存在旁边的 `nisaba-data`，请定期导出完整 `.rslbackup` 备份。移动程序前先关闭；升级时将新版本解压到新目录或空文件夹，再恢复旧版备份。

这是一份便携程序，不注册系统卸载项，不安装服务，也不修改 PATH。移除前先备份并关闭，再删除整个文件夹。删除整个目录会同时删除默认个人资料；其他位置的 PDF 和备份不会自动删除。

## 环境

支持目标为 Windows 10 / 11 x64，需要可用的 OpenGL 图形驱动。主要实测环境为 Win10 22H2；Win11、干净系统、物理断网及真实输入法候选窗的全面验收仍待补充。文件未进行代码签名。
